# Code de conduite

Nous adoptons le [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

En résumé : comportement respectueux, pas de harcèlement, critiques techniques constructives.

Les mainteneurs peuvent modérer issues, PR et discussions pour préserver un espace sûr.

Signalement : via les canaux de contact du dépôt ou Security Advisory GitHub.
