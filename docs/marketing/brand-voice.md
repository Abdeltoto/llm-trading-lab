# Voix de marque

## Principes

1. **Clarté avant hype** — Pas de promesses de alpha.
2. **Sécurité visible** — Répéter « simulation », « fictif », « pas de conseil ».
3. **Scientifique** — Hypothèses, biais, conventions de mesure explicites.
4. **Bilingue pragmatique** — UI en français ; README et issues accessibles en anglais.

## Ton

- Professionnel, direct, pédagogique.
- Éviter : « beat the market », « IA millionnaire », emojis excessifs sur le bandeau d’avertissement.

## Vocabulaire canonique

| Utiliser | Éviter |
|----------|--------|
| Simulation, argent fictif | Trading en direct, gains garantis |
| Campagne, concurrent, arène | Fonds, hedge fund |
| Coût API / budget IA | ROI magique |
| Exploratoire (backtest LLM) | Backtest validé sans réserve |
