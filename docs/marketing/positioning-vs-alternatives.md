# Positionnement (sans dénigrer)

LLM Trading Lab n’est **pas** un remplacement de Nautilus, QuantConnect ou d’un OMS institutionnel. C’est un **protocole d’évaluation LLM** avec exécution simulée intégrée.

| Besoin | Outil adapté | LLM Trading Lab |
|--------|--------------|-----------------|
| Exécution prod HFT | Nautilus, brokers | ❌ |
| Backtest quant classique ML | Qlib, Lean | Partiel (futur) |
| Démo multi-LLM reproductible | — | ✅ cœur |
| Journal décision + coût API | Rare dans les démos GitHub | ✅ |
| Zéro clé pour essayer | Variable | ✅ DEMO |

**Message marketing :** « Nous comblons le vide entre *benchmark vanity* et *moteur de production* — un banc d’essai **auditable** pour modèles génératifs sur allocation contrainte. »
